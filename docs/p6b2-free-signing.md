## 授权与申请状态

- Windows 客户端实现位于 Draft PR #70，已经进行受控测试，但尚无公开正式 Windows 发布记录。申请时必须如实说明这一点，请服务方判断首次发布资格。
- GitHub/签名账户 MFA 状态、审批人员及 SignPath 项目配置待确认；不声称已满足全部申请条件。
- 申请材料和隐私说明已经准备草案；在提交前核对最终发布版本、联系人、第三方说明和已发布记录。

## 签名和发布边界

仅提交通用客户端 EXE、安装脚本和 payload catalog。Device Bundle、Clash 控制密钥、上传密钥、客户 YAML、私有 VPS TLS 密钥和采样队列不提交给签名服务。

计划使用 GitHub-hosted 构建，并通过 SignPath 的来源核验和每次发布人工审批。具体账户和政策以正式批准的配置为准；普通 PR 不自动请求生产签名。

云端签名返回后仍须通过现有原生 Windows 签名、确切发布者指纹、时间戳、目录清单和每文件摘要验证。生产导出不允许未签名回退。代码签名私钥不放进 VPS 或客户端包，不通过安装器导入测试根证书以冒充公信发布。

获批并实际启用服务后，按服务方要求增加已获支持的署名；当前不宣称 SignPath 已为本项目签名。证书轮换须保留经过审查的身份连续性，不能只凭同名发布者放行。

## 数据流说明（申请前版本）

Windows 客户端在用户启用设备后，向设备配置绑定的 VPS 上传网络诊断结果，包括时间、网络测试状态与延迟、公网出口 IP 以及设备/位置/路径标签。本地控制密钥不作为样本上传。本地保存受限队列，用户可以暂停、移除、撤销和清理；本地删除不代表 VPS 历史数据立即删除。

联网检测会访问配置的 DNS/HTTPS/TCP 目标及 IPLark 等出口查询端点，相关服务可见连接所需的网络信息。客户端不自动修改 Clash/TUN。正式版本发布前须补齐并展示适用于最终构建的隐私及第三方说明。
